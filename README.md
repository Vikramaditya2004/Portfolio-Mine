## 👨‍💻 About

**Portfolio-Mine** is my personal developer portfolio website created to build and showcase my professional online presence.

The portfolio presents my development skills, projects, experience, education, and contact information through a responsive and interactive web interface.

The project is designed to be lightweight and easy to maintain without requiring a frontend framework or build system.

## 💻 Run Locally

Since this is a static website, no Node.js or package installation is required.

### 1. Clone the repository

```bash
git clone https://github.com/Vikramaditya2004/Portfolio-Mine.git
```

### 2. Navigate to the project

```bash
cd Portfolio-Mine
```

### 3. Open the website

Open `index.html` directly in a browser.

For development, **VS Code + Live Server** can be used for easier testing.

---

## 🔄 Update the Portfolio

After making changes locally:

```bash
git status
git add .
git commit -m "Update portfolio"
git push origin main
```

GitHub Pages can then publish the updated website according to the repository's deployment configuration.
