# 🌐 Portfolio-Mine

A personal portfolio website built to showcase Vikram Aditya's profile,
introduction, skills, and professional links in a simple and modern web
interface.

## 🚀 Live Portfolio

[View Portfolio](https://vikramaditya2004.github.io/Portfolio-Mine/)

## 📌 About the Project

**Portfolio-Mine** is a responsive personal portfolio website created
with **HTML and CSS**. The site presents a developer profile with a
focused hero section, navigation menu, profile image, animated role
text, social-media links, and a contact/hiring button.

The project is intentionally lightweight and can be opened directly in a
web browser without a build process.

## ✨ Features

-   👤 Personal introduction and profile section
-   💻 Developer-focused portfolio presentation
-   🧭 Fixed navigation header
-   ⌨️ Animated typing-style role text
-   🔗 Social media and professional profile links
-   📩 Direct email contact through the **Hire Me** button
-   📱 Responsive layout for smaller screens
-   🎨 Custom dark theme with accent styling
-   ✨ Hover animations and interactive UI effects
-   🔤 Google Fonts integration using Poppins
-   ⭐ Font Awesome icons for social links

## ⚙️ Run Locally

No Node.js, npm, or framework setup is required.

### 1. Clone the repository

``` bash
git clone https://github.com/Vikramaditya2004/Portfolio-Mine.git
```

### 2. Open the project

``` bash
cd Portfolio-Mine
```

### 3. Launch the website

Open `index.html` directly in a browser.

For a better development experience, use VS Code with the **Live
Server** extension.

## 🌍 Deployment

The project can be hosted easily using **GitHub Pages** because it is a
static HTML/CSS website.

The repository is configured with a GitHub Pages deployment workflow
under:

``` text
.github/workflows/
```

## 🔧 Customization

To personalize the portfolio:

1.  Open `index.html`.
2.  Update the name, introduction, social links, and email address.
3.  Replace `main.jpeg` with the desired profile image.
4.  Modify `index.css` to change colors, spacing, typography,
    animations, and responsive behavior.

The typing animation can be customized in the `@keyframes words` section
of `index.css`.

## 📱 Responsive Design

The CSS includes media queries for smaller screens. The navigation and
hero section adapt for mobile and tablet-sized displays, while the
profile image scales down appropriately.
